# Craftled — Brand reference

> Neutral craft-led docs shell — monochrome UI with chart accents, light and dark.

**Registry theme:** `theme-craftled` — `npx shadcn@latest add @craftled/theme-craftled`

**Theme mode:** light + dark (system)

## Rules

- Semantic tokens follow shadcn New York defaults (oklch neutrals)
- Shader blocks may use chart hues as decorative accents — not as primary button colors
- Variant panel exposes curated swatches only; no open hex pickers

## shadcn token mapping

Default `:root` / `.dark` in `app/globals.css` — the Craftled brand clears runtime overrides so these win.
